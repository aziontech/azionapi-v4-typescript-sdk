# Security Policy

## Supported Versions

This project follows a rolling-release model. Security fixes are applied to the
latest released version. Please make sure you are using the most recent release
before reporting an issue.

Releases are published at
<https://github.com/aziontech/azionapi-v4-typescript-sdk/releases>.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately through GitHub Security Advisories:

1. Open <https://github.com/aziontech/azionapi-v4-typescript-sdk/security/advisories/new>
2. Fill out the vulnerability report form
3. Submit the report

The same form is reachable from the **Security** tab of this repository, under
**Report a vulnerability**. Reports filed this way are visible only to the
maintainers until an advisory is published. If you are new to the process, see
GitHub's guide on
[privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

Please include as much of the following as you can:

- The affected version or commit
- Steps to reproduce, or a proof of concept
- The impact you believe the issue has
- Any suggested mitigation

## Response Timeline

| Stage | Target |
| --- | --- |
| Acknowledgement of your report | within 5 business days |
| Initial assessment and severity triage | within 10 business days |
| Status update cadence while we work on a fix | every 15 business days |
| Public disclosure after a fix ships | within 90 days of the report |

We will let you know if we expect to exceed any of these targets, and why.

## Disclosure

We follow coordinated disclosure. We ask that you give us the time above to
release a fix before disclosing publicly. When an advisory is published we will
credit you as the reporter, unless you ask us not to.

## Scope

This policy covers the SDK code in this repository. Vulnerabilities in the Azion
platform or in the underlying APIs should be reported through the same advisory
form, and we will route them to the appropriate team.
